# Stazione Aurora · Hacker Etico

Prototipo giocabile del serious game per l'hackathon Consorzio Clara + Cisco Networking Academy.

Gioca: https://sabb19.github.io/stazione-aurora/

Simulazione didattica: comportamento di rete semplificato e dichiarato. Nessun traffico reale lascia la pagina. La modalità Ologramma usa la fotocamera solo in locale (MediaPipe Hands) e richiede HTTPS.
